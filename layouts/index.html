What it will cover

Units, exact where the definition is exact.

Every item starts from the roadmap's bibliography, is validated against the tool that is the reference in its domain, and lands with tests at 100% coverage and a performance table: no slower than the reference on one core.

📏

Quantities

A dimension vector of rational exponents with a scale factor and an offset, so that degC and degF are units like the others.

⇄

Conversion

SI, US customary and derived units, and a parser for the UDUNITS grammar that NetCDF's CF conventions use.

π

Dimensional analysis

Compatibility checks and Buckingham's pi theorem, from the null space of the exponent matrix.

h

Constants

The CODATA 2022 values, generated from NIST's ASCII table with the edition recorded.

🧭

Unit systems

User-defined systems such as EMU, ESU and atomic units, in wave 4.

🚫

No existing Go package

None of the Go unit packages is a dimensional-analysis engine, so none is a dependency. Dates and time scales stay with go-datetime.

📦

Pure Go, CGO=0

On every architecture the fleet's CI tests.
